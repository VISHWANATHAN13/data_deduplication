# Data Deduplication Project

## Overview
The Data Deduplication project aims to identify and eliminate duplicate data entries within datasets. This is crucial for improving data quality, optimizing storage space, and ensuring the integrity of information.

## Features
- **Duplicate Detection**: Using algorithms to identify duplicate entries in datasets.
- **Data Cleaning**: Tools to cleanse datasets by removing duplicates and maintaining unique records.
- **User-Friendly Interface**: An intuitive interface for users to upload datasets and manage deduplication processes.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/VISHWANATHAN13/data_deduplication.git
   ```
2. Navigate to the project directory:
   ```bash
   cd data_deduplication
   ```
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
1. Run the main application:
   ```bash
   python app.py
   ```
2. Upload your dataset through the provided interface.
3. Select the deduplication options as per your requirement and start the process.
